## About

Kaito Kid has stolen the Moonlit Pearl and left a trail of clues across the Gulf. Work with Detective Conan to query the case database, follow the thief from one city to the next, and identify his final destination.


## Learning objective

Use SQL filters, sorting, limits, joins, comparison operators, and pattern matching to retrieve evidence from related tables.
