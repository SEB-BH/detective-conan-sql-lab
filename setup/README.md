## Setup




1. Create a database in your PGAdmin called `conan-case` and open up the query tool
2. Now copy the queries from [this file](../starter-data/case_database.sql) and paste them in the query tool and exectute the script. This is adding all the initial data in your database.
3. Now erase everything in the query tool and click open file in the top left corner:
![Open File](./assets/image%20(5).png)
4.  choose the clues file provided in the starter code folder in this homework [clues.sql file](../starter-data/clues.sql)
5. Now solve the lab with the clues given and when you're finished `control + s` to save the file in this directory
6. Push this file you saved to github.
